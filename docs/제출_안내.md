# 이어:봄 1.2.0 제출 묶음

일반 이용자는 `LinkSpring-Setup-1.2.0-x64.exe`를 Windows 10/11 64비트에서 실행합니다. Node.js·Python·개발 서버 설치는 필요하지 않습니다.

## 포함 파일

- `LinkSpring-Setup-1.2.0-x64.exe`: 전체 설치파일
- `README.md`: 공모전 `readme_v1.1.md` 기본 양식에 맞춘 설명, 실제 실행 화면 9장
- `docs/`: 사용자 안내, 기술 검증, 로고와 스크린샷
- `SHA256SUMS.txt`, `verification.json`: 설치파일 검증 자료
- `LinkSpring-Source-1.2.0.zip`: 현재 제출본 소스코드 스냅샷

## 심사자 체험

1. 설치 후 **예시로 체험**을 선택합니다. 별도 테스트 계정은 필요하지 않습니다.
2. 처리 대기 회기를 열어 후보 조건을 확인하고 연결·안내 과정을 체험합니다.
3. 실제 AI 호출은 **앱 설정 · 백업 → AI 연결 설정**에서 본인 API 키·모델을 설정해야 합니다. 설치파일에는 공용 키가 없습니다. AI 없이도 기본 업무를 체험할 수 있습니다.
4. 실제 AI 실행 결과는 README의 캡처로도 확인할 수 있습니다.

## 온라인 제출 전

- GitHub `hamhyeonggwang/linkspring_1.0`에 최종 소스와 README·이미지를 반영하고, 1.2.0 Release에 설치파일 및 SHA256SUMS.txt를 첨부합니다. 저장소 Source code ZIP과 설치파일은 다릅니다.
- 공개 다운로드 링크는 실제 게시 후 확인해야 합니다. 이 묶음 생성만으로 GitHub 자산이 업로드되지는 않습니다.
- 팀장 성명·직책은 제공받지 못해 README에 ‘제출자(1인 개발팀)’와 기관명을 기재했습니다. 제출 신청서와 일치하도록 확인하세요.
- 코치는 현종혁, 외부 전문가·개발자는 없음으로 반영했습니다. 확인되지 않은 현장 성과와 코칭 내용을 만들어 기재하지 않았습니다.
- Windows에서의 설치·실행 최종 검수는 실제 Windows PC에서 필요합니다. 검증 범위는 `docs/제출본_1.2.0_검증.md`에 기록했습니다.
