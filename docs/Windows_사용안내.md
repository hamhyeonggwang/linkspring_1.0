# 이어:봄 LinkSpring 1.2.0 — Windows 설치형

## 설치와 시작

1. `LinkSpring-Setup-1.2.0-x64.exe`를 Windows 10/11 64비트 PC에 다운로드합니다.
2. 설치파일을 실행하고 설치 위치를 선택합니다. 현재 Windows 사용자 계정에 설치합니다.
3. 바탕화면 또는 시작 메뉴의 **이어봄 LinkSpring**을 실행합니다.
4. 처음에는 **예시로 체험**을 선택해 가상 대기자 12명과 다음 평일의 빈 일정 2개로 연습하세요.
5. **실제 업무로 전환**하면 별도 저장소에서 업무를 시작합니다.

이 설치파일은 실행 환경을 포함합니다. 웹 서버, Node.js, Python, 클라우드 계정, API 키를 따로 설치하거나 설정할 필요가 없습니다. 기본 기능은 인터넷 없이 동작합니다. 이 빌드는 코드 서명 인증서가 없는 배포본이며 Windows가 확인되지 않은 게시자로 표시할 수 있습니다. 기관의 실행 정책을 따르세요.

## 기관 CSV 직접 불러오기 (1.1.0)

- 대기명단: `타임스탬프, 아동이름, 아동 생년월일, 보강치료 희망 날짜, 치료, 오전, 오후, 비고`
- 치료사 시간표: `Unnamed, 일자, 요일, 부서, 아이디, 치료사, 건수` 다음에 시간별 예약 열을 둡니다. 빈 첫 열과 `Unnamed: 0`도 지원합니다.
- 아동이름에는 사람마다 고유하고 다시 내보내도 유지되는 **익명 표시**가 들어 있어야 합니다. 별도의 가명 ID 열은 필요하지 않습니다. 같은 표시를 여러 사람에게 쓰면 같은 사람으로 처리되므로 전처리 단계에서 구분해야 합니다. 생년월일로 식별자를 만들지 않으며 생년월일·비고 원문은 저장하지 않습니다.
- 타임스탬프는 보강 신청일입니다. 후보의 대기 기간은 해당 희망 날짜의 신청일을 기준으로 계산합니다.
- 오전·오후는 `09:00`, `09:00~11:00`, `오후 2시`, `전체` 등을 지원합니다. 여러 시각은 CSV의 따옴표로 감싼 셀 안에서 쉼표로 구분합니다. 일치하는 30분 전체가 가능한 사람만 연결할 수 있습니다.
- 비고의 빈 값은 신규 신청에서 처리 대기이며, 재불러오기 시 기존 상태를 유지합니다. 자동 해석할 수 없는 비고·치료 표현은 미리보기에서 담당자가 상태·치료 종류를 선택합니다. 잘못된 행은 저장 전에 행 번호와 이유가 표시됩니다.
- 시간표 제목이 없거나 해석되지 않으면 미리보기의 ‘기관 표현 연결 · 시간표 해석’에서 **첫 시간·열 간격(10/30분)·예약 코드 반복 방식**을 선택합니다. 점심 열이 생략된 양식 등 간격이 불규칙하면 실제 시각 제목을 CSV에 넣어야 합니다.
- 여러 날짜가 있으면 반영할 날짜를 선택합니다. 선택 날짜의 시간표를 교체하지만 이미 등록된 결석·연결 회기를 지우는 교체는 거부합니다. 빈 셀은 미배정이며 결석으로 자동 등록하지 않습니다. 예약이 전혀 없는 파일은 반영하지 않습니다.
- 명단은 1,000행, 시간표는 500행·500회기까지 한 번에 가져옵니다. UTF-8 및 EUC-KR CSV를 지원합니다. 파일을 반복 반영해도 기존 내부 ID·중지 상태·최근 연결을 유지하며, 더 오래된 신청으로 최신 신청을 덮어쓰지 않습니다.
- 치료 일정은 **치료사 행 × 시간 열**입니다. 예약 칸을 누르면 결석 확인 화면이 열리고, 빈 회기 칸을 누르면 후보를 확인합니다. 대기자 관리에는 희망 일정과 최근 연결을 표시합니다.

## 업무 순서

1. **일정 직접 등록**에서 서비스 종류·날짜·담당자 코드·30분 일정을 입력합니다. CSV가 있다면 치료 일정 메뉴에서 미리보기 후 가져오세요.
2. **대기자 관리**에서 익명 코드·서비스·가능 시간·대기 시작일을 입력합니다. 별도로 배포될 Python 전처리 프로그램의 CSV도 가져올 수 있습니다. 전처리 프로그램은 필수가 아닙니다.
3. 실제로 결석이 발생하면 **빈 회기 등록**에서 시간표와 같은 날짜·시간·서비스·담당자 코드를 입력합니다.
4. 후보의 가능 시간과 대기 기간을 확인한 뒤 연결을 확정합니다. 근접 시간 후보는 추가 확인 대상으로, 그대로 확정할 수 없습니다.
5. 기관의 기존 전화·문자 절차로 안내하고 **안내 완료**를 기록합니다. 이 앱은 전화나 문자를 자동 발송하지 않습니다.
6. 퇴근 전 **백업**으로 `.sqlite` 파일을 안전한 장소에 저장합니다.

현재 버전은 30분 회기, 08:30~18:00 운영 시간(12:00~13:00 제외)을 지원합니다. 다른 회기 길이가 필요한 사업은 규칙 변경 후 사용해야 합니다. 확정 취소·되돌리기 UI는 현재 제공하지 않으므로 확정 전 정보를 검토하세요.

## 데이터 보관·복원

- 업무 데이터: `%LOCALAPPDATA%\LinkSpring\data\linkspring.sqlite`
- 체험 데이터: `%LOCALAPPDATA%\LinkSpring\data\demo.sqlite`
- 데이터는 현재 PC에만 저장됩니다. 여러 PC의 동시 공유·동기화 기능은 없습니다.
- 실명·연락처·진단명 대신 기관 내부에서 연결할 수 있는 익명 코드만 사용하세요.
- 앱 자체의 기관 계정 인증은 없습니다. Windows 사용자 계정, 화면 잠금, 기관 PC 접근 정책으로 보호하세요.
- 데이터와 백업 파일은 암호화되지 않습니다. 접근이 제한된 저장 위치를 사용하세요.
- **복원**은 1.0.0 또는 현재 버전에서 만든 백업을 선택하고 확인하면 현재 저장소를 교체합니다. 교체 직전 데이터는 같은 폴더에 `before-restore` 이름으로 자동 백업합니다.
- 앱 종료 후 다시 실행해도 데이터는 유지됩니다. 업데이트 설치와 앱 제거 시 업무 데이터는 기본적으로 보존됩니다. PC를 폐기할 때에는 기관의 보관 정책에 따라 별도 삭제하세요.
- 체험 초기화는 체험 데이터만 지웁니다. 날짜가 지난 예시는 사용 안내의 **체험 초기화**로 다시 만들 수 있습니다.

## AI 업무 도우미 설정과 사용

1. 왼쪽 **앱 설정 · 백업 → AI 연결 설정**에서 Anthropic Claude, OpenAI, Google Gemini 또는 OpenAI 호환 API를 선택합니다.
2. 해당 API 계정의 **함수 호출을 지원하는 모델 ID**와 API 키를 입력합니다. 웹 챗봇 구독과 API 이용 계정·요금은 별도일 수 있습니다. 호환 API는 `/chat/completions`까지 포함한 HTTPS 전체 주소가 필요합니다.
3. 전송 주소와 이용 요금을 확인하고 **AI 사용**에 체크한 뒤 **저장 후 연결 시험**을 누릅니다. 업무 데이터 없이 짧은 요청으로 연결을 시험하며 소량 과금될 수 있습니다.
4. **결석·빈 회기 등록:** 문장 입력 → 일정 정보만 추출 → 전송 내용 확인 → AI 분석 → 날짜·시간·서비스·치료사 수정 → 담당자 등록 순서입니다.
5. **처리 대기 → 회기 선택 → AI 후보 비교 실행:** 로컬 규칙으로 검증된 상위 5명의 차이와 확인할 사항을 읽고, 원본 후보 조건과 비교한 뒤 담당자가 연결을 확정합니다.
6. 연결 후 **AI 안내문 작성 → 검토·수정 → 검토한 안내문 저장**을 누릅니다. 저장된 문구를 복사해 기관 채널로 직접 전달하고 안내 완료를 기록합니다. 저장 이력에는 AI 초안 사용 여부가 남습니다.

키는 Windows 사용자 계정 기반 암호화로 별도 보관하며 업무 백업·설치파일에 포함하지 않습니다. 제공사나 전송 주소가 바뀌면 키를 다시 입력합니다. 체험 모드도 AI 설정 시 실제 호출이 발생합니다. 미설정·연결 실패·응답 검증 실패 시 **기본 결과 · AI 미사용**을 표시하며 업무를 계속할 수 있습니다. AI 응답에는 제공사·모델과 요청별 입력·출력 토큰을 표시합니다. 자동 호출이나 재시도는 하지 않습니다.

| 기능 | 외부 전송 항목 |
| --- | --- |
| 결석 분석 | 담당자가 확인한 일정 토큰과 기준일 |
| 후보 비교 | 서비스 종류, 요청마다 만든 C1~C5 번호, 대기 일수, 최근 서비스 연결 이후 일수, 시간 일치 여부 |
| 안내문 작성 | 안내 목적과 문체. 실제 날짜·시간·서비스는 PC에서 확정 기록으로 삽입 |

이름·기관 익명 표시·연락처·생년월일·CSV 원문을 후보 비교나 안내문 API에 보내지 않습니다. API 키는 선택한 제공사의 인증 헤더로만 사용합니다. AI 설명은 오류가 있을 수 있으므로 원본 조건과 비교하세요. AI는 의료적 우선순위, 연결 자격 또는 최종 연결을 결정하지 않습니다.

## 배포

GitHub Releases에는 `.exe` 설치파일과 `SHA256SUMS.txt`를 첨부합니다. 저장소의 Source code ZIP은 설치파일이 아닙니다. 기관 업무 데이터·백업·API 키는 GitHub에 올리지 않습니다. 별도 전처리 도구는 별도 배포하며 CSV 계약은 `docs/전처리_CSV_연계규격_v1.md`를 참조합니다.

다운로드 파일 검증(선택): PowerShell에서 `Get-FileHash .\LinkSpring-Setup-1.2.0-x64.exe -Algorithm SHA256` 결과를 배포자의 `SHA256SUMS.txt`와 비교합니다.
