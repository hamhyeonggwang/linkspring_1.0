## 실제 AI 검증

환경에 이미 설정된 API 키로 가상 데이터만 요청했습니다. 모델 목록 조회 후 사용 가능한 `claude-haiku-4-5-20251001`로 검증했습니다.

- 후보 비교: 가상 대기자 상위 5명의 임시 번호·대기 일수·최근 연결 여부를 보내 실제 설명을 받음. 최종 캡처 요청 기준 입력 1,216 / 출력 654 토큰.
- 안내문: 목적과 문체로 문구를 생성하고 PC에서 확정 일정을 삽입. 최종 캡처 요청 기준 입력 895 / 출력 126 토큰. UI에서 검토 저장 후 감사 이력과 안내 완료 확인.
- 결석 분석: 가상 날짜·오전 9시·작업치료·OT-01을 분석해 09:00~09:30 회기로 확인.
- OpenAI·Gemini·호환 API는 모의 HTTP 응답으로 인증 헤더, 요청 형태, 함수 호출 응답 처리와 토큰 해석을 검증함. 실제 제공사별 계정·모델 호출은 아직 검증하지 않음.

토큰 수는 위 개별 요청의 관측값이며 일반적인 사용 비용이나 정확도 지표가 아닙니다. AI의 자유 서술에는 의미 오류가 있을 수 있어 원본 후보 조건을 함께 보여주고 담당자 검토를 요구합니다.
