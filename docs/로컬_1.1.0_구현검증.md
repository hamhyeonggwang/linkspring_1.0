# 로컬 데스크톱 1.1.0 구현·검증 기록

작성일: 2026-09-17. 대상: Windows 10/11 x64. macOS 배포본은 만들지 않았다.

## 구현 범위

- 기존 스타일과 메뉴 구조를 유지하고 치료 일정 화면을 치료사 행 × 시간 열로 복원했다. 예약 셀에서 결석을 확인·등록하고 빈 회기에서 후보를 선택한다.
- 대기자 관리에 기관 익명 표시, 치료 종류, 날짜별 희망 시간, 신청일, 최근 연결을 표시한다. 데스크톱 설정·백업은 사이드바로 옮겼다.
- 사용자가 확정한 보강 신청 8열 양식과 익명 치료사 시간표를 직접 가져온다. 표준 CSV v1도 유지한다. 알 수 없는 치료·비고 표현과 제목 없는 시간 열은 미리보기에서 담당자가 해석을 선택한다.
- 외부 익명 표시와 내부 ID를 분리한다. 재불러오기·행 순서 변화에 관계없이 저장된 표시 대응을 재사용하며, 기존 중지 상태·최근 연결·완료 상태를 유지한다. 생년월일과 비고 원문은 저장하지 않는다.
- 여러 날짜의 시간표를 선택 반영한다. 이미 등록한 결석·연결 회기가 없어지는 시간표 교체는 전체 거부한다. 가져오기와 코드 대응 저장은 같은 트랜잭션이다.
- SQLite 추가 마이그레이션을 적용한다. 1.0.0 백업도 스키마와 마이그레이션 이력을 검증한 후 임시 파일에서 업그레이드해 복원한다. 현재 데이터의 자동 안전 백업과 원본 백업을 보존한다.

## 검증의 한계와 남은 확인

- 실행 검증 호스트는 macOS다. Windows에서 실제 설치·실행·제거 검증은 아직 수행하지 않았고 설치파일은 코드 서명되지 않았다.
- 기관 실제 CSV는 제공되지 않았다. 확정된 열 이름과 가상 값을 사용해 검증했다. 실제 시간 열 제목, 오전·오후 값, 익명 표시의 고유성·재추출 시 유지 여부는 기관 파일로 확인해야 한다.
- 같은 익명 표시는 같은 사람으로 처리한다. 여러 사람에게 동일한 마스킹 이름을 부여한 파일은 구분할 수 없다. 자동 식별이나 생년월일 해시로 보완하지 않는다.
- 운영 규칙은 08:30~18:00, 점심 12~13시 제외, 30분 회기다. 빈 셀은 미배정이며 결석이 아니다. 예약이 전혀 없는 파일은 반영하지 않는다.
- 알 수 없는 열 이름을 자유롭게 연결하는 범용 매핑 도구, 확정 연결 취소·되돌리기, 여러 PC 동기화는 이번 범위에 포함되지 않았다. 확정된 두 기관 양식과 표준 v1을 지원한다.

설치·사용 절차와 CSV 표현은 [Windows 사용 안내](Windows_사용안내.md)를 따른다. 이번 변경과 설치본은 로컬에 생성했으며 원격 커밋·푸시나 GitHub Release 게시는 수행하지 않았다.
